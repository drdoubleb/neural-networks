Nucleus Net

Teach a tiny neural network to read a blood count, then a nucleus — and watch every node and weight while it learns, from a single layer to a convolution.

One set of cases, one question

Question for the network

All the cases are synthetic, drawn by a script so that we know the truth for every one. 80 form the training set, which the network learns from. 20 are held out as a test set: the network never sees them during training, so they tell us whether it learned something general or merely memorised the training cases.

Click any case to put it under the inspector on the right, where you can see the numbers the network is given in stage 2 — and, for nuclei, exactly where each measurement comes from.

    Nucleus Net is a teaching toy: a small network with hand-written backpropagation — optional convolution, up to two dense hidden layers — trained in your browser on synthetic blood counts and nuclei. Keys: 1 2 3 switch stages, space trains or pauses, N classifies the next test nucleus. Regenerate the cases with node tools/generate_cbc.js and node tools/generate_nuclei.js.
